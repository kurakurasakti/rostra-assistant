

## 🟡 Tanpa domain custom — ini ok untuk sekarang, tapi catat

Pakai `glim.vercel.app` atau subdomain Vercel sementara tidak masalah untuk landing page awal. Tapi untuk kredibilitas UMKM Indonesia, domain `.id` atau `.com` worth diprioritaskan setelah ada revenue pertama. User akan lebih percaya `glim.id` dibanding `xxx.vercel.app`.

---

## ✅ Tanpa testimonial — solved dengan cara lain

Karena beta tester masih testing, jangan pakai testimoni palsu atau "coming soon". Ganti section testimonial dengan **"Dibangun untuk masalah nyata"** — ceritakan problem yang Glim solve berdasarkan riset awal kamu (girlfriend yang admin-nya sering sakit, dll) tanpa nama spesifik.

## Design Plan

**Warna:** `#0F3D3A` (deep teal — trust, dipakai bisnis serius soal uang), `#E8A33D` (warm amber — "glim" = kilau cahaya, dipakai untuk highlight momen AI "menyala"), `#F7F4EE` (warm off-white, bukan cream standar), `#1A1A18` (teks utama, hampir hitam tapi hangat), `#6B6862` (teks sekunder)

**Tipografi:** Display — sans geometris dengan karakter (seperti Sora atau General Sans), dipakai tegas di headline. Body — sans netral mudah dibaca (Inter). Utility/angka — monospace (JetBrains Mono) khusus untuk menampilkan harga dan data Rupiah — karena Glim berurusan dengan uang dan jadwal, angka harus terasa presisi.

**Signature element:** Mockup percakapan WhatsApp nyata di hero — pesan masuk dari klien, lalu draft AI muncul dengan efek "glimmer" halus (kilau emas sekilas) sebelum admin tap kirim. Ini bukan dekorasi — ini benar-benar mendemonstrasikan produk dalam satu visual.

## TEKNIS

Responsive mobile-first — mayoritas traffic UMKM
Indonesia akan dari HP.

Hero mockup WhatsApp chat: buat sebagai komponen
visual yang realistis — bubble chat dengan style mirip
WhatsApp asli (hijau untuk outgoing, putih untuk
incoming), tapi gunakan warna brand untuk elemen
glimmer/highlight saat AI draft muncul.

Animasi: gunakan dengan sengaja, bukan berlebihan.
Hero mockup bisa punya subtle animasi sekali saat
page load (pesan muncul satu per satu, lalu glimmer
effect saat draft AI muncul). Selebihnya halaman
statis — jangan animasi scroll-triggered di setiap
section, itu akan terasa generic.

Pastikan keyboard focus visible di semua interactive
elements (CTA buttons, FAQ accordion, register link).

CTA "Coba Gratis 14 Hari" dan variannya semua harus
link ke /register (route yang sudah ada dengan
invite code system — landing page ini untuk awareness,
bukan untuk bypass invite code system yang masih aktif
selama beta).

---

## CATATAN PENTING

Karena masih dalam fase beta dengan invite code,
landing page ini untuk AWARENESS dan SEO purposes.
Visitor yang klik CTA akan diarahkan ke /register
yang masih require invite code.

Pertimbangkan tambah text kecil di dekat CTA:
"Saat ini masih tahap beta terbatas — daftar untuk
masuk waiting list" — TAPI hanya jika register page
benar-benar masih gated. Konfirmasi ke user dulu
apakah register masih invite-only atau sudah open
sebelum menambahkan copy ini.
