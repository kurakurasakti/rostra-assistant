# Changelog

All notable changes to this project will be documented in this file. See [standard-version](https://github.com/conventional-changelog/standard-version) or [Release Please](https://github.com/googleapis/release-please) for commit guidelines.

## 1.0.0 (2026-08-25)

### Features

- WhatsApp CRM and AI auto-reply assistant for tailoring SMBs
- AI message classification and secure draft reply generator
- Business knowledge extraction and structured profile storage
- Escalation rules and few-shot conversation learning
- WhatsApp connection via Baileys gateway service
- Multi-channel notification bell and scheduled messages engine
- Customer and order management with Excel/CSV bulk import
- Automated versioning and CI release pipeline with Google Release Please
